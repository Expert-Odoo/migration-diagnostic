What it does

Every Odoo upgrade starts with the same questions: how many custom modules, how much data, which specifics will slow things down. Migration Diagnostic answers them in seconds.

📦

Module inventory

Classifies every installed module as standard Odoo, OCA or custom / third-party — the biggest driver of migration effort.

📊

Data volumes

Counts the critical records — partners, products, orders, journal entries, messages, attachments — to size the project.

⚠️

Risk factors

Flags multi-company, custom fields, Python server actions, accounting localizations and high volumes, each with a recommendation.

🎯

Complexity score

A global score from 0 to 100 and a clear level — Low, Medium, High or Critical — to position your migration at a glance.

⏱️

Effort estimate

A workload range in person-days, computed from modules, volumes and residual risks — so you can budget instead of guess.

🗺️

Phased migration plan

A recommended migration order — reference data first, then business data — with the key watch-outs, model by model.
